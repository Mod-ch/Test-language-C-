# C Programming Exercises

Exercices de programmation en langage C réalisés dans le cadre de ma formation
en Réseaux et Systèmes Sécurisés à l'Institut Supérieur du Numérique (SupNum),
Nouakchott.

## Contenu

- `agree.c` : demeande si l'utilisateur est agree ou nom
- `uppercase.c` : transforme les mots un upperercase  (Majiscule)
- `liearSearch.c` : effectie des recherches linier

## Compilation et exécution

```bash
gcc lierarSecrch.c -o programme
./programme
```
